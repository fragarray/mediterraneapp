# Corso di Marketing

Questa cartella è il pacchetto autonomo del corso. Apri `index.html` per la prenotazione, `en.html` per l’inglese e `admin.html` per la gestione. Esegui `sql/create_marketing_course.sql` in Supabase. Le API nella sottocartella `api/` devono essere copiate nella cartella API del progetto Vercel: le Serverless Functions Vercel non vengono eseguite da una cartella pubblica `sito/marketing/api/`. Tabelle: marketing_eventi, marketing_prenotazioni, marketing_settings.
